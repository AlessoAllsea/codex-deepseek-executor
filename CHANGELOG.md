# Changelog

## 1.1.0 — 2026-10-18

- First public package with a bundled standard-library Python executor.
- Independent per-user configuration instead of machine-specific launcher paths.
- Isolated Harness home with a reference to the existing managed credential store.
- Explicit-only skill invocation, fixed provider/endpoint and preserved write sandbox/approval.
- Nonblocking stdin, bounded output, process-group cleanup and private result files.
- Offline tests, bilingual installation docs, MIT license and contribution/security guidance.

The earlier 1.0.0 package was a private machine-specific prototype and is not part of this public repository's history.
